# pi-web

[English](https://github.com/aiti-ai/pi-web/blob/main/README.md) | [中文文档](https://github.com/aiti-ai/pi-web/blob/main/docs/README.zh-CN.md) | [日本語](https://github.com/aiti-ai/pi-web/blob/main/docs/README.ja.md)

**AITI Web** (`@aiti-ai/pi-web`) — браузерный рабочий стол для [агента pi](https://github.com/earendil-works/pi) и основа экосистемы инструментов [aiti](https://aiti.pw/): инструменты отладки с внедрением в страницы, MCP-мост для AI-агентов и большая библиотека встроенных расширений.

Этот репозиторий — заглушка. Сам рабочий стол — дистрибуция `@aiti-ai/pi-web` (форк апстрим- [pi-web](https://github.com/agegr/pi-web) с 63+ встроенными расширениями), его документация и вся экосистема aiti (расширения, pi-пакеты, инструменты) — находятся в монорепозитории **[aiti-ai/aiti-ai](https://github.com/aiti-ai/aiti-ai)**:

- Рабочий стол (установка, документация, исходники): <https://github.com/aiti-ai/aiti-ai>
- TUI-мост: [@aiti-ai/pi-web-bridge](https://github.com/aiti-ai/aiti-ai/tree/main/pi-plugins/pi-web-bridge) — подключение TUI-сессии pi к рабочему столу командой `/web` (живой просмотр + двусторонний ввод/вывод)
- Сайт: <https://aiti.pw>
